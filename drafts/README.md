# Drafts

This directory is a backlog for half-formed posts. Nothing here is part of the Astro content collection, so drafts do not build or publish.

Number filenames when an intended writing or publication order matters. Unrelated ideas can stay unnumbered.

When a draft becomes an active post, move it into `src/content/blog/` on a working branch and preview the real site output. Published post filenames use:

`yyyy-mm-dd-post-slug.md`

The URL slug stays independent of the filename. Use the real publication date when publishing; do not use placeholder dates to manage the backlog.
