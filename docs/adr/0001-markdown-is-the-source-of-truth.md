# Markdown is the source of truth for content

The Posts and Pages were first imported from a Ghost export, but that export and the Ghost content folder no longer exist. The Markdown files in `src/content/blog/` are now the only copy of the content and are edited by hand (for example, written descriptions and recovered cover images), so the Ghost importer and its tests were removed rather than kept around where re-running them could fail or overwrite hand edits.
